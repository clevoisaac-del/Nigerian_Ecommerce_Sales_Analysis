Nigerian E-commerce Sales Analysis

Project Overview

This project analyzes a Nigerian e-commerce sales dataset to identify sales performance, order trends, product performance, delivery outcomes, cancellations, and other business insights.

The analysis was conducted using Python, Pandas, Matplotlib, and Excel.

Objectives

The main objectives of this project were to:

- Analyze overall sales performance
- Identify sales and order trends over time
- Analyze order status and cancellation patterns
- Compare sales performance across branches
- Identify top-performing products
- Examine product sales per unit
- Generate visual insights to support business decisions
- Provide recommendations for improving sales and order fulfillment

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Microsoft Excel
- Data Analysis
- Data Visualization

Dataset

The project uses the Nigerian E-commerce Sales Dataset.

The dataset contains information including:

- Order ID
- Item Price
- Packed Quantity
- Quantity
- Total Price
- Order Date
- Order Status
- Branch

The dataset covers transactions from February 2021 to May 2021.

Key Findings

Some of the major findings from the analysis include:

- Total sales: approximately ₦1.78 billion
- Total orders: 2,406
- Total quantity sold: 222,719 units
- Average order value: approximately ₦741,083
- Lagos generated the largest share of sales among the analyzed branches.
- Order cancellations represented a significant portion of the orders analyzed.
- The analysis identified products with particularly strong sales performance.
- Sales and order outcomes varied considerably across the four months analyzed.

Analysis Performed

1. Sales Performance Analysis

Analyzed total sales, order volume, quantity sold, and average order value.

2. Branch Analysis

Compared sales and order performance across Nigerian branches, including Lagos, Oyo, and Ogun.

3. Order Status Analysis

Examined:

- Delivered orders
- Cancelled orders
- Invalid orders
- Failed deliveries
- Other order outcomes

4. Product Analysis

Identified top-selling products and compared product sales performance.

5. Time-Series Analysis

Analyzed sales and order patterns across the months covered by the dataset.

6. Data Visualization

Created charts to communicate important findings and make the analysis easier to understand.

Business Recommendations

Based on the analysis, businesses could:

1. Investigate the major causes of order cancellations.
2. Improve order confirmation and fulfillment processes.
3. Monitor branch-level performance more closely.
4. Focus inventory and marketing efforts on high-performing products.
5. Investigate declining sales or order-performance trends.
6. Use regular data analysis to monitor operational KPIs.
